## Task Breakdown

### Task 1 - Admin Settings General Tab
**[Code](https://github.com/manoj-mukkamula/UpToSkills/tree/main/Task-1)**

Built the General Tab of an Admin Settings page in plain HTML, CSS, and Vanilla JavaScript for handoff to another intern.

- Followed the UptoSkills BrandKit design tokens for consistent styling
- Built form sections for platform name, contact email, timezone, and language settings
- Toggle switches, input fields, and save button with clean layout
- Fully responsive and structured for easy handoff

---

### Task 2 - Admin Dashboard
**[Code](https://github.com/manoj-mukkamula/UpToSkills/tree/main/Task%202)**

Built the Admin Dashboard for LittleSteps, a daycare marketplace platform, using React, Vite, and Recharts.

- Followed the Figma design closely through multiple rounds of visual refinement
- Stats cards showing key platform metrics
- Interactive charts using Recharts for data visualization
- Recent activity feed and quick action buttons
- Component-based architecture with mock data
- Clean, responsive layout matching the provided design

---

## What I Did in This Internship

I handled both tasks end to end: understanding the Figma designs, building the components, matching the visual output precisely, and refining based on feedback. Task 1 was built in vanilla HTML/CSS/JS for handoff purposes. Task 2 was built in React with Vite, using Recharts for charts and mock data for all dashboard metrics.
